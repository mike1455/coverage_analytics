# data/input: сюда кладите выгрузки

Приложение по умолчанию берёт файлы **из этой папки**. Положите сюда файлы под этими именами, и в приложении останется нажать «Загрузить из папки выгрузок».

| Что | Имя файла | Нужен |
|---|---|---|
| Реестр МКД МЖИ | `19.10.26_МКД_SELECT_t_content_code_AS_Код_t_content_District_AS_Округ_t_cont_202610191348.xlsx` | да |
| SQL № 2, все адреса, одна строка на дом | `Запрос № 2. Выгрузка № 1 — ВСЕ адреса, одна строка на дом.csv` | да |
| SQL № 3, адреса и подъезды | `Запрос № 3. Выгрузка № 2 — ВСЕ адреса и подъезды, одна строка на подъезд.csv` | да |
| SQL № 4, заявки 2026 | `Запрос № 4. Выгрузка № 3 — заявки 2026 по дому И по подъезду в ОДНОМ файле.csv` | да |
| Геоданные (unom, lat, lon или GeoJSON) | любое имя, впишите его в окне «Папка с выгрузками» | нет |

Длинные тире в именах оставлены как есть: так DBeaver назвал файлы.

**Не нужны** (класть не обязательно, приложение их пропустит): запросы № 1 и № 5 (контрольные), № 6 (платные дефекты), `SQL-запросы ... .md`.

## Если имена другие

Переименовывать не обязательно. Откройте в приложении раздел «Импорт и качество данных», кнопку «Папка и имена файлов», и впишите свои имена (или выберите из подсказки со списком файлов этой папки). Можно указать и другую папку или полный путь к файлу. Настройки сохранятся в `config/sources.local.json`.

Имена по умолчанию задаются в `config/sources.default.json`.

## Где ищутся файлы

1. Эта папка, `data/input` внутри приложения.
2. Если здесь нужных файлов нет, запасная папка `%USERPROFILE%\Desktop\Выгрузка по адресам\ФАЙЛЫ ИТОГ` (и её вариант в OneDrive).

## Конфиденциальность

Всё содержимое этой папки, кроме этого README, **исключено из git** (`.gitignore`): реестры и выгрузки не попадут в репозиторий, даже если выполнить `git add -A`.

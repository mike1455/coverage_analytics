# data/local — ваши локальные файлы

Положите сюда файлы, которые приложение должно найти само (кнопка «Импортировать эти файлы» на стартовом экране и в разделе «Импорт / качество»):

- реестр МЖИ: `*.xlsx` или `*.csv`;
- выгрузки ЕДЦ: `01_дома.csv`, `02_подъезды.csv`, `03_заявки_2026.csv` или объединённые `Дома_ЕДЦ_2026_с_заявками.csv`, `Подъезды_ЕДЦ_2026_с_заявками.csv`;
- геоданные: `*.csv` (unom, lat, lon) или `*.geojson`;
- офлайн-подложку `moscow.pmtiles` (создаётся командой `py -3 tools/get_basemap.py`).

Всё содержимое этой папки, кроме этого README, **исключено из git** (`.gitignore`), поэтому реестры и выгрузки не попадут в репозиторий.
